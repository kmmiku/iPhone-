# iPhone-课程表自动闹钟 · 快捷指令
自动读取日历课程，生成上午与下午 首节课闹钟
课程表自动闹钟快捷指令
作者：GitHub@kmmiku
功能：根据系统日历中的每日课程，自动在凌晨创建当天上午和下午第一节课的闹钟，并自动清理旧闹钟，全程静默运行。

前提条件：
iOS 17 及以上系统（需要“删除闹钟”操作）。

安装“快捷指令”App（系统自带）。

打开“设置”---搜索“快捷指令”---高级---允许不确认直接删除--勾选✔

课程表已通过 Wakeup课程表 或其他课程软件导入系统日历（建议将所有课程放在同一个日历下，如命名“课程表”）。

使用步骤
第一步：导入课程表到日历
使用 Wakeup课程表（或超级课程表、课程格子等）将课表一键导出到系统日历。
右上角转发按钮---导出到日历---右上角导出
确保所有课程归属在同一个日历中（例如“课程表”），方便快捷指令筛选。



第二步：导入快捷指令
点击下方链接将本快捷指令添加到您的设备：
https://www.icloud.com/shortcuts/3db6f14dd0914c5ba8fc641875ee3e55


第三步：设置个人自动化（定时运行）
打开「快捷指令」App → “自动化” →右上角➕号→特定时间

触发条件选 “特定时间”，时间设置为 凌晨 0:00 至 6:00 之间（确保早于当天第一节课），重复 “每日”。

点击“下一步”，添加操作 “运行快捷指令”，选择您导入的“课表闹钟”。

关键：在下一步界面，关闭“运行前询问”和“运行时通知”，使闹钟在后台自动创建。

点击“完成”保存。



第四步：运行测试
首次设置后，手动运行一次快捷指令（点击指令卡片上的播放按钮）。
然后打开系统“时钟”App，检查是否生成了当天课程的闹钟，并且闹钟标签为“早上起床”与“下午起床”



自定义与优化
调整提前量：打开快捷指令，找到两个“调整日期”操作，分别修改“减去”的分钟数（如上午提前30分钟，下午提前15分钟）。


闹钟标签：确保“创建闹钟”操作中的标签统一为“课表”，以便自动删除。

常见问题
Q：某天没有课程，会怎样？
A：指令会检测到日程数为零，自动跳过创建，不会报错，也不会产生任何闹钟。

Q：运行后闹钟没生成，怎么办？
检查当天日历中确实有课程。

确认“查找日历日程”选择了正确的日历。

检查自动化是否关闭了“运行前询问”。

在“设置 → 隐私 → 日历”中，允许“快捷指令”访问日历。

Q：会误删我手动设置的其他闹钟吗？
A：不会。删除操作只针对标签为“课表”的闹钟，不影响其他闹钟。

Q：为什么要在凌晨运行，而不是晚上？
A：因为快捷指令读取的是“今天”的课程，只有过了0点，“今天”才代表当前日期，凌晨运行能保证当天课程被正确获取，并且闹钟在起床前就已设定好。
